=================================

Open index.html directly in a modern browser. No build step is required.

WHAT'S INCLUDED
- Premium black / champagne-gold visual system
- CSS 3D hero ring with mouse interaction
- Interactive collection cards
- Responsive mobile layout
- Showroom/map CTA using the supplied Google Maps short link
- Phone CTA
- CSS-generated jewellery artwork, so the demo has visuals without depending on stock-image licensing

The design takes broad UX inspiration from premium online jewellery stores such as BlueStone, but the layout, styling and artwork are original.
